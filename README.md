# Movie Recommendation System

## Overview
This project is a Movie Recommendation System built using the MovieLens Small dataset. It recommends similar movies using collaborative filtering and cosine similarity.

## Objective
To recommend movies to users based on movie rating patterns.

## Technologies Used
- Python
- Pandas
- Scikit-learn

## Dataset
- MovieLens Small Dataset

## Features
- Loads movie and rating datasets
- Creates a user-movie matrix
- Uses collaborative filtering
- Recommends the top 5 similar movies

## How to Run

1. Install the required libraries:
```
pip install -r requirements.txt
```

2. Run the program:
```
python movie_recommendation.py
```

3. Enter a movie name from the dataset to get recommendations.
